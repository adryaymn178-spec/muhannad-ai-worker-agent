# Muhannad AI Worker Agent — MVP

نسخة أولية تجريبية لوكيل مهام ذكي:
- Dashboard عربية ومتجاوبة للهاتف.
- إدارة حالة الوكيل.
- مهام تجريبية.
- تحليل/تنفيذ مهام كتابة وترجمة وتلخيص وإدخال بيانات.
- فحص جودة بسيط.
- سجل عمليات.
- أرباح تجريبية.
- نقطة API واحدة للـ backend.

مهم:
هذه النسخة لا تتصل بأي منصة خارجية ولا تنفذ تسجيل دخول أو تجاوز CAPTCHA.
عند ربط منصة لاحقًا يجب استخدام API/OAuth الرسمي وشروط المنصة.

## التشغيل محليًا

Backend:
```bash
cd backend
pip install -r requirements.txt
python main.py
```

ثم افتح:
http://127.0.0.1:8000

يمكنك أيضًا فتح `frontend/index.html` مباشرة، لكن تشغيل الـ backend يعطيك بيانات تجريبية عبر API.

## متغيرات البيئة

انسخ `.env.example` إلى `.env` وأضف مفاتيحك فقط عند الحاجة. لا تضع مفاتيح حقيقية داخل GitHub.
